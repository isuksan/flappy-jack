# flappy-jack

Flappy Jack web game and iframe integration assets.

## File structure

```
.
├── README.md
├── iframe-integration-spec.md
├── package.json
├── publish/
└── src/
    └── index.html
```

## Getting started

- `npm start` serves `src/` via `http-server`.
- `npm pack` creates a tarball in `publish/`.
